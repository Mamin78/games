# Games

Small browser games, each in its own folder. Play them at **https://mamin78.github.io/games/**.

| Game | What it is |
| --- | --- |
| [Twofold](https://mamin78.github.io/games/twofold/) | Merge matching neighbors until one tile is left. Endless puzzles on 3×3, 4×4 and 5×5 boards, with hints. |

## Twofold

The rules follow LinkedIn's daily Sumbreak puzzle. This project is not affiliated with LinkedIn.

- Drag a tile onto a neighbor (up, down, left or right) that shows the same number. They merge into their sum on the tile you drop onto.
- Empty squares stay empty and nothing slides into them, so the order of merges matters.
- Wildcards merge with any number: ×2 doubles it and +3 adds 3. Two wildcards can't merge with each other.
- You win when one tile is left.

Each board is generated by running merges backwards from a single tile, so every board can be solved. A built-in solver grades difficulty and powers the hints. When the board can no longer be solved, the "Last good move" button rewinds you to your last solvable position.

The game is one file, `twofold/index.html`, with no build step and no dependencies.

## Adding a game

1. Create a folder named after the game, with an `index.html` inside.
2. Add a card for it to the root `index.html`.
3. Give its saved data a unique `localStorage` key prefix, because every game on this site shares one origin.
